# EXASCALE — Assets et licences

Les boîtiers, glyphes de modules, câbles, particules et motif silicium sont dessinés en code exclusivement pour EXASCALE. La nappe sonore Web Audio est une composition procédurale originale, sans échantillon musical externe. Aucun téléchargement n'est nécessaire au lancement du jeu.
